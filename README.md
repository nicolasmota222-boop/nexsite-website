# NexSite agency website

A framework-free, responsive website for NexSite — a custom website-building agency for businesses ready for their next move.

## Files

- `standalone.html` — self-contained preview; no server or build step required.
- `index.html` — editable page source.
- `styles.css` — responsive visual system, layout, accessibility, and motion rules.
- `script.js` — mobile navigation, project-type switcher, scroll reveals, and brief-copy interaction.

## Creative direction

NexSite is positioned as a signal studio: the work turns a good business into a clearer next step for its audience. The page uses a black-and-white base with patina teal, lime, and a warm coral signal. Bricolage Grotesque gives the brand a distinct, slightly engineered voice while Manrope keeps practical information readable.

The signature interaction is the live project brief: visitors can switch between launch, rebuild, and system work, then copy a short starting brief without filling out a dead form.

## Before launch

The site is deployable as-is as a static project. The contact address is `NexSiteToday@gmail.com`; the contact actions are intentionally mailto-based so they work without a backend.
